# 2026-10-10 安全修复与部署接口

本说明替代旧 Runbook 中“只生成 algo-UUID.env 就完成自动切换”的描述。
源码、脚本、helper 与 damod 必须作为一组审核、部署；不能仅替换一个脚本。
本补丁测试全部使用公开合成数据，不表示已经完成真实路由器部署或联网认证。

## 数据配置与旧格式迁移

`portal.current.conf` 可继续使用逐行 `KEY='literal'`，或无特殊字符的未引用字面量。
读取时不执行 Shell，不支持 source、eval、变量展开、命令替换、双引号表达式、引号拼接、重复字段和未知字段。
JSON 对象是新的规范写入格式：字段和值均为字符串；更新后扩展名仍可以是 `.conf`。
原文件中注释会在规范化后消失，但全部已支持字段值保留。

字段白名单：

```
TICKET_URL AUTH_URL CLIENT_ID USER_AGENT SCHOOL_ID DOMAIN AREA
HOST_NAME OSTAG IPV4 IPV6 MAC GATEWAY SYSNAME MACHINE IFNAME
GSM_NETWORK_TYPE SDK ALGO_ID CIPHER_SCHEME
DOUBLE_DES_KEY DOUBLE_DES_IV DES_KEY_FIRST DES_KEY_SECOND
TEA_KEY_0 TEA_KEY_1 TEA_KEY_2 TEA_IV
RAW_TEMPLATE RAW_KEY RAW_IV TRUSTED_PORTAL_HOSTS
```

在私有、root 拥有、不可被其他用户写入的部署目录中，先备份再对副本操作：

```sh
umask 077
cp -p portal.current.conf portal.pre-security.conf
cipher-helper config-normalize portal.pre-security.conf portal.staged.conf
cipher-helper config-set portal.staged.conf TRUSTED_PORTAL_HOSTS 'ticket.example,auth.example,verified-keep.example'
cipher-helper client portal.staged.conf self-test
```

`TRUSTED_PORTAL_HOSTS` 是明确的逗号分隔主机名/IP白名单，不支持通配符。请使用此前已人工验证的运营商端点，不从新下载的网页自动扩充。
默认允许已配置 TICKET/AUTH 主机；不同 keep 主机必须显式加入白名单。URL 仅允许 http/https、有效主机、无 userinfo/fragment/控制字符。
网络发现的 ticket/auth 路径必须与现有配置一致；keep 路径必须是 `/keep.cgi`。HTTPS端点不得降级到HTTP。ticket/auth任一配置为HTTPS时，保活URL也必须HTTPS，即使keep主机在显式白名单中亦不能降级。alternate只替换主机/端口、不降低原scheme，并重新执行同一信任/TLS策略；原始全HTTP门户仍兼容。
允许真实门户的非XML HTML中嵌入唯一 `<ticket-url><![CDATA[...]]></ticket-url>` 与 `<auth-url>...</auth-url>`；只提取这两项有界标量数据，不执行HTML或脚本。
保留本地 ticket 查询串；WAN更新以 URL 查询参数解析更新 clientip/wlanuserip。

## 加密就绪与兼容

- `cipher-helper list` 只列能力，不代表已加载密钥。
- `check ALGO_ID` 仅在所需密钥/IV长度正确且密钥不全零时成功。缺密钥不产生密文，不 panic。
- 不要求私有文件增加注册函数：仍兼容 `keydata_local.go` 的 `init()` 对既有变量赋值。本公开构建不携带任何真实密钥。
- 客户端优先使用已加载静态算法；否则安全解析原有 `9ABF4D29`、`3DES2`、`TEA3-CBC/ECB` 显式参数，保留旧层序及各自填充：9ABF4D29双3DES-CBC只补齐非对齐输入，不强制NUL；3DES2与TEA3仍强制NUL再补齐。独立固定向量覆盖7/8/9/16字节输入，不能以往返自检替代。不能用缺密钥的helper check跳过验证。
- `RAW_TEMPLATE/RAW_KEY/RAW_IV` 三项在规范配置中直接接入 ticket/auth/keep；不 source `algo-UUID.env`，不把运行时密钥放在新流程的命令行参数。
- raw 模板严格匹配已知名字，不再子串猜算法。未验证的16字节DES密钥返回受控错误，不猜测两密钥3DES协议语义。
- `client ... self-test` 只是配置加密往返，不是门户协议向量测试、服务端授权或联网证据。

## 路由器local-time兼容

脚本通过设备自身 date +%z 导出 PORTAL_TIME_OFFSET（严格±HHMM）。Go按该偏移生成local-time，不依赖缺失的/etc/localtime/zoneinfo，也不硬编码用户时区。
直接运行helper/candidate-activate而未设置该环境变量时，Go仅调用固定 date +%z，2秒超时、最多32字节输出，再严格校验；无法确定或非法偏移会失败，不静默退回UTC。
回归覆盖+0800、-0530、-0030、非法/空值、缺date和超长输出；这次从Shell迁Go引出的时区兼容已锁定。

## 自动候选激活与回滚

脚本稳定部署名字保持：`portal_auto_auth.sh`、`portal_client_openssl.sh`、`cipher-helper`、`damod`。
仓库中对应源文件是 `router/portal_auto_auth.with-damod.sh`、`router/portal_client_openssl.helper.sh`。
所有步骤串行执行，无并发常驻Go程序。

1. 下载新模块到私有随机目录；HTTP失败、截断、非法容器失败关闭。
2. `damod -json` 校验容器UUID、LZMA、ELF节表和唯一已验证模板，输出只进入0600临时文件。
3. `candidate-prepare` 检查模块与metadata UUID一致、字段边界、能力和加解密往返；制作候选配置。
4. 新验证通过的模块以随机临时文件原子替换缓存。不读取或信任旧非空缓存，坏下载/解包不发布；下一次重试重新下载，因此坏缓存不能永久阻止正常下载替换。
5. 候选配置真正执行 ticket/auth；响应需完整且唯一的response根、唯一必要子字段，无根外字段/非法结构。XML实体/CDATA正常解码，合法账号密码字符统一转义。
6. 旧HTTP协议的 `Error-Code != 0` 明确失败（`200` 表示算法模块）；日志仅保留数值错误码，不泄露正文、密码、ticket或密钥。没有猜造XML result/status/code成功字段。
7. 候选独立探测必须返回HTTP204，拒绝空200与重定向；成功后才写本地新会话及配置（配置最后写）。此后调度器直接进入保活状态，不再退避/重复认证。
8. 失败候选不修改活动参数和本地会话。普通写入失败/并发冲突回滚本事务仍持有的值，不覆盖外部编辑；无法完整恢复时明确报错。Linux CLI写入使用非阻塞flock；手工编辑仍应停服务，避免最后一次比较与rename之间的不可消除竞态。

**限制：** 这不是跨多个文件的断电原子事务。硬断电/SIGKILL恰在最终多文件发布期间，可能留下部分会话文件；部署必须保留旧配置/会话备份，停服务后统一恢复，重新认证。失败候选认证是否影响运营商远端旧会话也不能由本地回滚保证；本地旧会话保留不等于远端会话仍有效。

## HTTP、输出与资源

HTTP由helper内置net/http完成，正确处理chunked，严格有界且不跟随跳转。不再依赖wget的状态输出选项，不需要curl/xmllint/xmlstarlet/Python；不完整nc后备已删除。
客户端不再生成ticket请求密文、原始响应、共享`/tmp/portal-keep-response.xml`等诊断文件；旧 `PORTAL_KEEP_RESPONSE_FILE` 不再使用。
调度器临时文件位于mktemp私有目录；session/config/cache使用随机0600临时文件+rename，并拒绝已有软链接/非普通文件。
建议部署目录0700，配置/凭据/会话0600，二进制/脚本0700。

| 资源 | 上限 |
|---|---:|
| 配置、门户页面、XML明文 | 64KiB |
| 加密HTTP响应/CLI stdin | 128KiB |
| HTTP响应头 | 16KiB |
| 模块容器 | 512KiB |
| ELF解压实际输出 | 1MiB，必须与声明大小一致 |
| LZMA字典声明 | 16MiB |
| 实际LZMA字典分配 | max(4096, min(声明字典, 已知输出大小))，最多1MiB |
| ELF节数、节表项 | 最多1024、项至少64字节，算术防溢出 |
| ELF节名 | 单名最多128字节；扫描窗口先限129字节；累计扫描/复制含NUL预算16KiB，重复偏移也计费，复制前拒绝超限 |

当前固定版本xz读取器在有界已知输出头下会降低实际字典分配；显式ReaderConfig.DictCap=16MiB避免默认2GiB声明上限。
脚本设置默认 `GOMEMLIMIT=6MiB`（Go GC软目标，不是RSS硬限）。真实OpenWrt的峰值RSS、证书存储、BusyBox ash行为需主线程另行验收。
HTTP门户和模块没有新增数字签名；明文HTTP原协议仍依赖可信网络，白名单不消除链路MITM风险。未知容器类型/新模板拒绝自动启用。

## CLI接口（部署/验证工具用）

```
cipher-helper client CONFIG ticket|auth|keep|self-test
cipher-helper probe URL TIMEOUT_SECONDS
cipher-helper config-get CONFIG KEY
cipher-helper config-set CONFIG KEY VALUE [KEY VALUE ...]
cipher-helper config-normalize INPUT OUTPUT
cipher-helper config-wan CONFIG IPV4
cipher-helper portal-page CONFIG URL OUTPUT
cipher-helper module-fetch CONFIG OUTPUT
cipher-helper candidate-prepare ACTIVE METADATA_JSON MODULE OUTPUT
cipher-helper endpoint-prepare ACTIVE PAGE OUTPUT
cipher-helper candidate-activate ACTIVE CANDIDATE PROBE_URL TIMEOUT ATTEMPTS DELAY
cipher-helper cache-publish MODULE OUTPUT EXPECTED_UUID
cipher-helper xml-validate                  # stdin
cipher-helper xml-get FIELD                 # stdin
```

client/candidate-activate 通过环境读取 PORTAL_USER/PORTAL_PASSWORD（调度器仍从私有portal.user/password读入）。
原有 PORTAL_SESSION_TICKET_FILE/KEEP_URL_FILE/INTERVAL_FILE 保留；缺省输出位置是配置文件所在目录。
HTTP204探测地址由 PORTAL_PROBE_URL 指定；默认仍是原部署generate_204站点。可选独立探针用于人工排除单站点故障；仅单站点失败不能证明门户拒绝。
（2026-10-11 起调度器自动使用备用探针，见 `CHANGES-2026-10-11-lock-and-probe-fallback.md`；单实例锁也已迁到 `/var/run`。）
`once` 现在需要认证及独立204验证才返回0；`algo/refresh` 只有真正激活候选才返回0，没有变化或失败返回非零。

## 公开树确定性验证

无需真实keydata_local.go、账号、密码、服务器或路由器：

```sh
(cd cipherhelper && go test ./... && go vet ./...)
(cd tools/damod && go test ./... && go vet ./...)
sh -n router/portal_auto_auth.with-damod.sh
sh -n router/portal_client_openssl.helper.sh
sh tests/backoff.sh
sh tests/state-transition.sh
node tests/regression.cjs
(cd tools/damod && go test -fuzz=FuzzELFSectionTable -fuzztime=3s -parallel=1)
(cd tools/damod && go test -fuzz=FuzzUntrustedContainer -fuzztime=3s -parallel=1)
```

Windows回归默认采用项目已有Go/Node/Git sh路径。其他平台可设置 PORTAL_TEST_GO/PORTAL_TEST_SH/GOPATH；该Node测试仅监听127.0.0.1，使用OS随机临时目录和合成模块，退出后清理。
`tests/regression.cjs` 驱动真实二进制与真实shell：截断下载→下次完整替换坏缓存、候选拒绝、空200回滚、raw认证及保活、chunked、严格探测、配置注入拒绝、非XML HTML端点激活。
`backoff.sh/state-transition.sh`只对状态/时间/日志/凭据检查等外围做桩，不证明真实OpenWrt权限或网络行为。
补充最终审查回归：`tools/damod/section_names_test.go` 仅用小ELF验证超长、别名、不同偏移和复制前预算拒绝（不运行约1GiB恶意放大）；`cipherhelper/review_regression_test.go` 固定独立向量验证旧fallback语义及保活TLS/alternate策略。
软链接单元测试在Windows不能创建链接时会明确skip，必须在Linux/OpenWrt补测，不能记作本机已通过。
